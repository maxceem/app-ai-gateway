---
title: Limits
description: Set how many requests and how much spend each install, each Apple Account, each user and the whole app may have.
---

An app's **Limits** tab sets the limits you place on the app's own callers, and
on the app as a whole. Leave a field empty for no limit. Click **Save limits** to
save. How the limits are counted, and the refusals they give, are on
[Limits and blocking](/how-it-works/limits).

## For each of the app's users

- **Requests per minute**: per install on an iOS app, per user on a server app.
- **Requests per day**: the same.
- **Monthly budget ($)**: dollars a month, such as `25` or `0.50`.
- **Whose month the budget counts** (iOS apps only): **Each Apple Account**,
  the default; **Each install**; or **Each signed-in user**, which needs
  **Signed-in users only**. See
  [Whose month an iOS budget is](/how-it-works/limits#whose-month-an-ios-budget-is).

These limits need an app that names its callers. On an app with **No end users**
the card says the app can only be limited as a whole. To limit each user, first
choose who may call on the app's **Sign-in** tab.

## For the whole app

The same three fields, shared by all installs, users and keys of the app. A
refusal from them stops everybody's traffic, so an app that backs off one user
will not clear it.

## In the settings

```json
"limits": {
  "per_user": {
    "requests": { "per_minute": 30, "per_day": 1000 },
    "spending": { "monthly_nano": 10000000000, "scope": "apple_account" }
  },
  "per_app": {
    "requests": { "per_minute": null, "per_day": null },
    "spending": { "monthly_nano": 100000000000 }
  }
}
```

- Budgets are in **nano-dollars**: one dollar is `1000000000`. The console shows
  and takes dollars; the settings store whole nano-dollars, so a budget never
  rounds.
- The block may be left out: then the app has no limits.
- `per_minute`, `per_day` and `monthly_nano` may each be `null`, which means no
  limit for that field alone. A request limit must be a whole number above `0`.
  A budget may be `0`, which refuses every request it covers, even one that
  would cost nothing, whenever the month's spend can be read.
- `per_user` limits on an app with no end users are refused when you save. A
  `per_user` block of `null`s is accepted.
- The key is `per_user` on every kind of app. `spending.scope` is
  `apple_account`, `install` or `user`. Left out, it is `apple_account` on an iOS
  app and `user` on a server app. `user` on an iOS app needs signed-in users, and
  a server app takes only `user`: it has no installs and no Apple Accounts.
