---
title: App settings
description: Rename an app, turn it off so it refuses every request without losing anything, edit its whole configuration, or delete it.
---

An app's **Settings** tab holds what is not on the other tabs.

## Name and status

**Name** can be changed at any time with **Rename**. The app's ID cannot: it was
fixed when the app was created, and it is part of every URL your app calls.

**Turn off** makes the app refuse every request with `403 app_disabled`. Nothing
is deleted, and **Turn on** brings it back as it was. Use it to stop a
misbehaving release or a runaway client while you look into it.

## Configuration

The app's whole configuration, as JSON: the same document the other tabs edit.
**Check** asks the gateway whether it would accept it, without saving.
**Save configuration** saves it. If someone else saved the app since you started
editing, the tab says so and keeps your edits, so you can decide.

Every setting is described in the
[app settings reference](/automation/agent-manual#application-configuration-reference).

## Conversation history

Whether the gateway keeps a copy of this app's calls, and for how long. See
[Conversation history](/applications/conversations).

## Delete this app

**Delete app** asks you to type the app's ID. Then every call the app makes is
refused, and its keys stop working. In normal operation that reaches every
request within a minute; see
[When changes take effect](/how-it-works/apps-and-providers#when-changes-take-effect).

Its usage history is kept in your account's totals. Its stored conversations
become unavailable at once, and are deleted later, so download any you want to
keep first. The app's ID is never given to another app.

## Through the API

- `PUT /v2/admin/apps/{app}` with the whole body updates the name, the
  configuration and the status. Include the `revision` from your latest read, so
  a change someone else made since is not overwritten.
- `PATCH /v2/admin/apps/{app}` changes only the settings you name: its body is a
  list of `operations`, with the `revision` from your latest read. The same
  checks apply. See the [API guide](/automation/api).
- `DELETE /v2/admin/apps/{app}?confirm={app}` deletes the app. `confirm` must
  repeat the app's ID.
