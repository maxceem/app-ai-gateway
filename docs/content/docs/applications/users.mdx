title: Users
description: See who is using the app, what each user has spent, and block a user who is running up your bill.

An app's **Users** tab lists every user the app has named, with their
**Status**, this month's **Requests** and **Cost**, and when they were **Last
seen**. On an iOS app with **Anyone with the app**, every user is one install, and
the user ID is the install's App Attest key.

A user appears once the app first gets a gateway token for them, or, for a server
that names users in a header, once their first call is recorded.

Search by user ID with **Search by user id**. **Next** moves to the next page.

## Blocking

**Block** refuses every request from the user, on every install they hold, with
`403 auth_required`. It reaches every request within ten seconds. **Unblock**
lets them back in the same way.

A block is not a limit. Limits reset; a block stays until you lift it.

A user named only by an app install can shed a block by reinstalling the app,
because that makes a new install. A user named by a sign-in token cannot.

Users your server names in a header are listed from their usage, and cannot be
blocked here: the gateway never checks who they are. Stop them in your server
instead.

## Through the API

- `GET /v2/admin/apps/{app}/users`, with optional `month` (`YYYY-MM`), `query`
  (part of a user ID), `status` (`active` or `blocked`), `limit` (1 to 200) and
  `offset`.
- `GET /v2/admin/apps/{app}/users/{user}` for one user.
- `POST /v2/admin/apps/{app}/users/{user}/block` and `…/unblock`.
