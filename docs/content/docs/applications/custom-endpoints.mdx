---
title: Presets
description: Keep the provider connection, model, settings and fallbacks on the gateway behind a stable name, so you can change them without an app release.
---

A preset is a URL of your own whose connection, operation and model live in
the app's settings instead of in the app:

```text
POST https://api.appaigateway.com/v2/apps/{app}/presets/{slug}
```

The app sends only its request's own content. You decide, and can change at any
time, which connection and model serve it, which settings are fixed, and what
to fall back to when the provider fails. A preset does not depend on the app's
**Providers** tab: the preset itself says what it may call.

## Adding one

On the app's **Presets** tab, click **Add preset** and fill in:

- **Name**: 1 to 64 characters from `a-z`, `0-9` and `-`. It is the last part
  of the URL, so name it for what it does, such as `chat` or `transcribe`, not
  for the model behind it.
- **Provider**: one of your provider connections.
- **Operation**: the kind of request it sends, such as `openai.responses` or
  `openai.transcription`. Your app's request must be in that operation's format.
- **Model**: change it at any time; the app keeps calling the same name. The
  model must have a price, or saving is refused.
- **Most output tokens**: optional. A request that asks for more is refused;
  one that names no limit gets this value written in.
- **Fixed parameters (JSON)**: optional. Merged into each JSON request, winning
  over the app's values. Use it for what every request should send, such as an
  image size or a voice.
- **Add fallback**: optional. More connections and models to try in order when
  an attempt gets no answer, a `429` or a `5xx`. Each must speak the same format
  as the preset's operation, such as `xai.responses` behind `openai.responses`.
  Leave a fallback's operation empty to use the connection's first operation in
  that format.

Click **Save presets** to save.

## What the app sees

The request is checked exactly like a provider proxy request: a gateway token or
an app key, plus `X-App-Version` with a gateway token. Limits, usage and the
error format are the same. The answer keeps the serving provider's own format,
and streams as it arrives. An unknown name is refused with
`404 preset_not_found`. See [Calling presets](/integrate/endpoints).

The app's model rewrites do not apply to presets: a preset names its models
itself.

## Fallbacks

Because targets name a connection, a fallback can be a second connection of the
same provider: `openai` falling back to `openai-dev` moves traffic to a second
key with no change to the request.

- The first target must work. A missing connection, an operation it cannot
  serve or a key that cannot be opened refuses the request before anything is
  spent. A first connection you turned off is skipped, so its fallbacks can
  serve.
- A fallback that cannot work, because its connection is gone or turned off, is
  left out of the chain.
- Every attempt is recorded as its own charge. A failed attempt costs nothing.

The app's **Usage** tab can group charges by preset.

## In the settings

```json
"presets": {
  "chat": {
    "provider": "openai",
    "operation": "openai.responses",
    "model": "gpt-5.4-mini",
    "params": { "reasoning": { "effort": "low" } },
    "max_output_tokens": 4096,
    "fallback": [{ "provider": "openai-dev", "model": "gpt-5.4-mini" }]
  },
  "transcribe": {
    "provider": "openai",
    "operation": "openai.transcription",
    "model": "gpt-transcribe"
  }
}
```

The keys of `presets` are the names in the URL. `params`, `max_output_tokens` and
`fallback` may be left out. A fallback's `operation` may be left out.
