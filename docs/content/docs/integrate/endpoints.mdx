---
title: Calling presets
description: Send a request to a preset, and let the gateway choose the connection, model and settings.
---

A [preset](/applications/custom-endpoints) is a URL whose connection, operation
and model are set on the gateway:

```text
POST https://api.appaigateway.com/v2/apps/{app}/presets/{name}
```

Only `POST` is served. A preset checks who is calling exactly as the
[provider proxy](/integrate/proxy#headers-your-app-sends) does, so it takes the
same headers:

- an app key, on a server app with no signed-in users;
- an app key and the end-user header you named, `X-End-User-ID` by default, on
  a server app that sends the user ID;
- a gateway token with `X-App-Version` on an iOS app or a server app with
  signed-in users, plus `X-AppAttest-Proof` where the app checks App Attest on
  every request.

Limits, usage and errors work the same way.

## The body

A preset may have [fallbacks](/applications/custom-endpoints#fallbacks): other
connections and models tried in turn. Each one tried is an **attempt**.

Send a body in the format of the preset's operation, as its provider documents
it. Leave out `model`: the gateway sets the preset's model for each attempt,
in the body, the form, or Gemini's path. A model you send is replaced.

| Operation's format | Example body |
| --- | --- |
| Responses | `{"input": "…"}` |
| Chat Completions | `{"messages": [{"role": "user", "content": "…"}]}` |
| Anthropic Messages | `{"max_tokens": 1024, "messages": [{"role": "user", "content": "…"}]}` |
| Gemini `generateContent` | `{"contents": [{"parts": [{"text": "…"}]}]}` |
| Image generation | `{"prompt": "…"}` |
| Embeddings | `{"input": "…"}` |
| Transcription | A `multipart/form-data` upload with a `file` field |

- The preset's **Fixed parameters** are merged into a JSON body, nested objects
  included, and win over your values. An upload gets no fixed parameters.
- The preset's **Most output tokens** applies as on the proxy.
- A transcription must be an upload with a `file` field, or it is refused with
  `400 invalid_request`. Its `response_format` follows the rules on the
  [proxy](/integrate/proxy#transcription).
- An image edit may be an upload too. Every other format takes JSON only.
- On an Anthropic Messages preset, the gateway sends
  `anthropic-version: 2023-06-01` if your request has no `anthropic-version`
  header. Yours wins when you send one.
- Your URL's query is not sent to the provider, except `alt=sse` on Gemini,
  below.

The examples use an app key, for a server app with no signed-in users. For
the other setups, change the headers as listed above.

```sh
curl https://api.appaigateway.com/v2/apps/example-app-a1b2c3/presets/chat \
  -H "Authorization: Bearer $APP_AI_GATEWAY_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input":"Suggest a 500 kcal lunch."}'
```

```sh
curl https://api.appaigateway.com/v2/apps/example-app-a1b2c3/presets/transcribe \
  -H "Authorization: Bearer $APP_AI_GATEWAY_KEY" \
  -F file=@note.m4a
```

## The answer

The answer is in the format of the provider that served it. When a preset falls
back from one provider to another, such as from OpenAI's Responses API to
xAI's, the answer is the second provider's. Both have the same shape, but read
the usage and any provider-only fields with care.

## Streaming

Stream as on the proxy: set `"stream": true` and read the event stream. On a
Gemini `generateContent` preset, add `?alt=sse` to the preset's URL instead, as
Gemini's own API does: the gateway calls Gemini's streaming method for you. On
an iOS app that signs every request, the query is part of what is signed, so
add it before you sign.

A fallback is tried only when the attempt before it got no answer, a `429` or a
`5xx`, so a stream that has started is never switched to another provider. All
attempts share one time limit for the provider's response headers: a fallback gets
what is left of it. See [Limits on one request](/integrate/proxy#limits-on-one-request).

## Errors

| Answer | Meaning |
| --- | --- |
| `404 preset_not_found` | The app has no preset with this name. |
| `404 not_found` | The method was not `POST`. |
| `502 provider_not_configured` | The preset's first connection was removed, or none of its connections is left to serve it. |
| `502 provider_disabled` | The preset's connection is turned off and it has no fallback left. |
| `502 provider_unavailable` | The preset's first connection cannot serve its operation, or its key cannot be opened. |

When every attempt fails, your app gets the result of the last attempt actually
sent: that provider's own error, `502 provider_error` if the connection failed,
or `504 provider_error` if the time limit ran out. A fallback that is skipped,
for example because its key cannot be opened, leaves the earlier result in
place. The gateway's errors, and how to handle
them, are in [Errors and limits](/integrate/errors).
