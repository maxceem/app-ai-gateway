## What the gateway owns

- Provider credentials are per organization, encrypted at rest, and write-only.
- D1 stores tenant configuration, users, credentials, and usage events.
- One Durable Object per organization holds its monthly request allowance.
- Provider-native bodies and streaming response formats remain intact.
- The administration console and API configure the deployed instance.

## What your application owns

Your application supplies its identity policy and its allowed provider paths and
models. An issuer such as Firebase decides who may obtain a mobile gateway token.
Trusted servers can use a long-lived per-application API key instead.
