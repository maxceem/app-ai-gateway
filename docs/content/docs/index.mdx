App AI Gateway is a multi-tenant, provider-native proxy for iOS applications
and trusted server backends. It authenticates users, enforces the limits you
set on your own users, holds the organization to its monthly request
allowance, and streams model responses straight from the providers your
organization brings its own keys for.

## What the gateway owns

- Provider credentials are per organization, encrypted at rest, and write-only.
- D1 stores tenant configuration, users, credentials, and usage events.
- One Durable Object per organization holds its monthly request allowance, and
  one per user serializes the limits an application sets on its own users.
- Provider-native bodies and streaming response formats remain intact.
- The administration console and API configure the deployed instance.

## What your application owns

Your application supplies its identity policy, its allowed provider paths and
models, and the request or spending limits it puts on its own end users. An
issuer such as Firebase decides who may obtain a mobile gateway token. Trusted
servers can use a long-lived per-application API key instead.
